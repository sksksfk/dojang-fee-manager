# 태권도장 월회비 관리 앱

브라우저에서 수련생과 월회비, 현금·카드·계좌이체 및 부분 납부를 기록하는 정적 웹 앱입니다.

## 시작

- GitHub Pages 주소를 열고 첫 화면에서 비밀번호를 설정합니다.
- 신규 수련생 기본 회비는 150,000원이며 설정에서 바꿀 수 있습니다.
- 납부 이력은 브라우저의 localStorage에 저장됩니다. 다른 기기와 자동 동기화되지 않습니다.

## 연말 현금 납부 출력

연도별로 현금 결제 기록을 수련생 및 월별 합계로 출력합니다. 장부 기록을 정리하는 확인용이며 국세청 공식 교육비 납입증명서, 현금영수증, 세액공제 자격 판정이 아닙니다. 세법상 대상 여부와 공식 증빙은 국세청·세무 전문가에게 확인해야 합니다.

## 개인정보 주의

이 앱은 서버 저장·계정 동기화 기능이 없습니다. 기기를 공유하거나 브라우저 데이터를 삭제하면 정보가 노출되거나 사라질 수 있으므로, 민감한 수련생 정보를 입력하지 말고 정기 백업 기능이 필요한 실제 운영 환경에서는 서버형 시스템을 사용하세요.
